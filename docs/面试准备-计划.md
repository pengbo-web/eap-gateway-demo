## 二、主文档结构

- **§1 一页纸速览**:30 秒电梯稿、3 分钟完整版讲稿(背景→架构→难点→结果)、ISA-95 定位
- **§2 架构全景**:代码地图(24 类职责表)、一条事件的端到端旅程(10 步)、部署视图、EapEvent 字段表、配置分层(yml 静态 / Redis 运行时)
- **§3 简历逐条深挖**(核心,每条固定七段式):
  1. 简历原文 → 2. 白话解释 → 3. 代码地图 → 4. 原理深挖(协议帧图/公式/机制)
  → 5. 数字出处(实测值+复现命令) → 6. 拷打 Q&A(每条 10+ 个递进追问与答法)
  → 7. 弱点与应对(诚实清单+改进方向)
  - 条1 多协议接入:MBAP 帧/解码器五参数/事务号/退避重连;HSMS 状态机/10字节头/SECS-II 编码/S6F11/S2F41/W-bit;paho 补订阅
  - 条2 事件总线:拓扑与双队列扇出、不丢三件套逐环节、三跳幂等失效域分析、seq/mid 分工、压测对账方法论(窗口归属/清零口径/预热轮/200路=逻辑通道口径)
  - 条3 时序存储与 SPC:超级表建模/DURATION/REST+HikariCP/时区坑/ts 单调防护/建表双检锁;X̄-R 公式推导、A2/D4 系数、三规则、防自证偏差、边缘判异 vs FDC
  - 条4 监控与可靠性:事件即心跳、离线判定阈值推导(3×pollMs+扫描粒度→4.1s)、配置缓存分层、MTBF/MTTR/可用度区间模型与检测口径
- **§4 横向拷打专题**:不丢不重全景表、三个时间戳与时钟偏差、模拟器体系与自研理由、与两个 MES 的关系边界、生产化差距(被问"真上线怎么改")、八股联动(Netty/RabbitMQ/Redis/TDengine)
- **§5 排障故事集**(STAR 格式 ×6):MBAP off-by-one、TDengine 三坑、压测对账差1(同毫秒 upsert)、remark 毒消息循环、paho 补订阅、建表双检锁失效
- **§6 考前速记单**:数字总表、公式卡、术语表、代码文件索引、危险问题 Top10 一句话答法

## 三、写作纪律(质量线)

1. **每个数字可追溯**:标注实测环境与脚本,口径分开(独立/共存/低负载),不许出现无出处数字;
2. **每条声称可映射到代码**:写到类与方法名,面试官说"打开代码看看"不慌;
3. **弱点主动交代**:D4 系数表已备但 R 图判异未启用、publisher confirm 回调未消费(以落库对账兜底)、LatencyStats 环形缓冲用 ArrayList.remove(0)、Linktest 只应答未主动发起、200 路为逻辑通道单连接多 topic——全部写进"弱点与应对",被动被挖不如主动准备好;
4. **答法给到句子级**:Q&A 不只给要点,给可以直接说出口的完整回答;
5. **与项目二联动**:OEE(项目二) vs 可用度(项目一)口径区分、MES 消费端(EapMqConsumer)归属讲清,防止两项目边界被问穿。
